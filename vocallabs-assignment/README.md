# Vocallabs Founder's Office Assignment Execution Hub

## Operating Context
- **Company**: VocalLabs (Bangalore, 2024, ~22-30 employees, Pre-seed/Bootstrapped)
- **Founders**: Mritunjoy Das (IIT Madras), Rag Sanil, Nileesh Kumar
- **Core Product**: White-Label Voice AI Infrastructure Platform (resold by Agencies, BPOs, SaaS, Telcos)
- **Product Suite**: VocalStack Voice, Vocalassist AI, Vocallabs Identity, MCP Server, VocalFlow (OS), PocoDisk (OS), Vocal Dialer
- **Portal**: Hiringg (app.hiringg.ai/vocallabs) - dogfooded AI hiring platform
- **Resale Model**: Partners buy infrastructure at partner rates, set resale pricing, retain margin.

## Execution Rules & Philosophy
1. **Ship, don't slide-deck exercise**: Every output must represent a production-ready, defensible business decision.
2. **Defensible Numbers**: Quantitative metrics tied specifically to VocalLabs' unit economics, partner CAC, and API consumption models.
3. **No Filler**: Zero generic slide/doc fluff. Tight narrative, single sharp recommendations.
4. **Toolchain**:
   - `python-pptx` & `reportlab` for clean deck & PDF generation.
   - `matplotlib` & custom SVG/PNG generators for visual architecture/funnels.
   - Markdown PRDs & GTM briefs.
   - 120-second video script tuned for 1-take natural camera delivery.

## Directory Structure
- `01_strategy/`: Positioning, TAM/SAM/SOM, Unit Economics, PRD, GTM Frameworks
- `02_pitch_deck/`: Slide narrative, Python PPTX generator, exported presentations
- `03_visuals/`: System architecture diagrams, product UI mockups, visual charts
- `04_video_script/`: 120-second script split into 0-30s / 30-90s / 90-120s blocks
- `05_submission/`: Final submission bundle, text responses, link manifest, QA checklist
